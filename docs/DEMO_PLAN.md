# Demo plan — 3 minutes

Opens on the browser pane completing the task, not on the camera.
The camera recognition appears second, as the reason the browser knew what to type.
The audit timeline appears early as proof of category, not as a closing flourish.

Anti-project defence: this is not an image analyzer and not a dashboard.
The image is the input; the completed, approved web action is the product.

- 0:00-0:20  the problem, stated once
- 0:20-1:40  one unbroken live run: object -> grounded mask -> draft -> approval
- 1:40-2:20  what was built during the event, and the audit log
- 2:20-3:00  limits stated honestly, and what comes next
